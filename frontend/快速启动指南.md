# 🚀 多设备同步功能快速启动指南

## ✨ 自动化数据库初始化

**好消息！** 数据库表结构会在应用启动时自动创建，无需手动执行SQL脚本！

### 🔧 自动化机制

项目已配置以下自动化功能：

1. **JPA自动建表**: `application.yml` 中的 `ddl-auto: update` 会自动创建和更新表结构
2. **启动检查**: [`DatabaseInitializer.java`](../backend/src/main/java/com/ebook/config/DatabaseInitializer.java:1) 会在启动时检查表结构
3. **数据库自动创建**: 连接字符串中的 `createDatabaseIfNotExist=true` 会自动创建数据库

## 📋 首次启动时会自动创建的表结构

### user_settings 表
```sql
CREATE TABLE user_settings (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    font_size INT DEFAULT 16,
    theme VARCHAR(20) DEFAULT 'light',
    reading_mode VARCHAR(20) DEFAULT 'default',
    line_height DECIMAL(3,1) DEFAULT 1.5,
    page_width INT DEFAULT 800,
    auto_save_progress BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    UNIQUE KEY unique_user_settings (user_id)
);
```

### reading_progress 表新增字段

## 🐛 常见问题解决

### 问题1: 数据库连接失败
```
Error: Could not connect to database
```
**解决方案:**
1. 确保MySQL服务正在运行
2. 检查 `application.yml` 中的数据库配置
3. 确认用户名密码正确

### 问题2: 表创建失败
```
Error: Table 'user_settings' doesn't exist
```
**解决方案:**
1. 检查MySQL用户是否有CREATE权限
2. 手动执行 [`init-sync-tables.sql`](../backend/src/main/resources/init-sync-tables.sql:1) 脚本
3. 重启应用

### 问题3: 前端API调用失败
```
Error: 404 Not Found /api/user/settings
```
**解决方案:**
1. 确认后端服务已启动
2. 检查JWT token是否有效
3. 查看浏览器网络面板的错误信息
