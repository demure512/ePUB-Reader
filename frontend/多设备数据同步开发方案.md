# 🛠️ 本地开发多设备同步方案

## 🎯 开发阶段目标
在本地环境完成多设备数据同步功能开发，确保所有用户数据存储在数据库而非本地存储，为后续上云部署做准备。

## 📋 当前项目状态分析

**已实现（云端存储）：**
- ✅ 用户账号系统（MySQL）
- ✅ 图书文件存储（服务器文件系统）
- ✅ 图书元数据（MySQL）
- ✅ 部分阅读进度（MySQL中的reading_progress表）

**需要迁移（本地→云端）：**
- ❌ 用户设置（字体大小、主题等）- 当前在localStorage
- ❌ 阅读器状态（当前章节、滚动位置等）- 当前在localStorage
- ❌ 临时缓存数据 - 当前在localStorage

## 🏗️ 本地开发方案

### 1. 数据库结构扩展

**新增用户设置表：**
```sql
-- 在现有MySQL数据库中添加
CREATE TABLE user_settings (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    font_size INT DEFAULT 16,
    theme VARCHAR(20) DEFAULT 'light',
    reading_mode VARCHAR(20) DEFAULT 'default',
    line_height DECIMAL(3,1) DEFAULT 1.5,
    page_width INT DEFAULT 800,
    auto_save_progress BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    UNIQUE KEY unique_user_settings (user_id)
);
```

**增强阅读进度表：**
```sql
-- 为现有reading_progress表添加字段
ALTER TABLE reading_progress 
ADD COLUMN current_chapter VARCHAR(200),
ADD COLUMN scroll_position INT DEFAULT 0,
ADD COLUMN total_pages INT DEFAULT 0,
ADD COLUMN device_info VARCHAR(100),
ADD COLUMN last_sync_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP;
```

```
用户设置管理：

阅读进度管理：
GET    /api/books/{id}/progress     # 获取详细阅读进度
PUT    /api/books/{id}/progress     # 更新阅读进度
POST   /api/books/{id}/sync         # 手动同步进度
GET    /api/user/recent-reading     # 获取最近阅读记录
```

### 3. 前端开发任务

**Store重构：**
- 创建 `settingsStore` - 管理用户设置
- 扩展 `bookStore` - 增强阅读进度管理
- 修改 `authStore` - 登录时同步用户数据

**组件修改：**
- 阅读器组件：从API获取/保存设置
- 设置页面：实时同步到服务器
- 进度组件：定时自动保存

**同步策略：**
```javascript
// 登录时同步
async initializeUserData() {
  await this.fetchUserSettings()
  await this.fetchReadingProgress()
}

// 实时同步设置
async updateSetting(key, value) {
  // 立即更新本地状态
  this.settings[key] = value
  // 异步同步到服务器
  await this.syncSettingsToServer()
}

// 定时同步进度
setInterval(() => {
  this.syncReadingProgress()
}, 30000) // 每30秒同步一次
```

## 🚀 上云部署方案

### 1. 代码准备阶段

**环境配置分离：**
```
application.yml          # 通用配置
application-dev.yml      # 本地开发配置
application-prod.yml     # 生产环境配置
```

**构建脚本准备：**
```bash
# build.sh - 生产构建脚本
#!/bin/bash
# 后端构建
cd backend
mvn clean package -Pprod

# 前端构建
cd ../frontend
npm run build

# 打包部署文件
tar -czf ebook-library-deploy.tar.gz backend/target/*.jar frontend/dist/ scripts/
```

### 2. 华为云部署步骤

**步骤一：云资源准备**
1. 购买ECS云服务器（2核4GB，Ubuntu 20.04）
2. 购买RDS MySQL实例（2核4GB）
3. 配置安全组（开放80、443、8080端口）
4. 申请公网IP和域名

**步骤二：服务器环境搭建**
```bash
# 安装Java 8
sudo apt update
sudo apt install openjdk-8-jdk

# 安装Nginx
sudo apt install nginx

# 安装Node.js（用于前端构建，可选）
curl -fsSL https://deb.nodesource.com/setup_16.x | sudo -E bash -
sudo apt-get install -y nodejs
```

**步骤三：应用部署**
```bash
# 上传部署包
scp ebook-library-deploy.tar.gz ubuntu@your-server-ip:/opt/

# 解压和配置
tar -xzf ebook-library-deploy.tar.gz
sudo mkdir -p /opt/ebook-library
sudo cp -r * /opt/ebook-library/

# 配置生产环境数据库连接
# 修改application-prod.yml中的数据库连接信息
```

**步骤四：服务启动**
```bash
# 启动后端服务
cd /opt/ebook-library
nohup java -jar -Dspring.profiles.active=prod ebook-library.jar > logs/app.log 2>&1 &

# 配置Nginx代理前端
sudo cp nginx.conf /etc/nginx/sites-available/ebook-library
sudo ln -s /etc/nginx/sites-available/ebook-library /etc/nginx/sites-enabled/
sudo systemctl restart nginx
```

**步骤五：数据迁移**
```bash
# 导出本地数据
mysqldump -u root -p ebook_library > ebook_library_backup.sql

# 导入到云数据库
mysql -h your-rds-host -u username -p ebook_library < ebook_library_backup.sql

# 上传电子书文件
rsync -avz uploads/ ubuntu@your-server-ip:/opt/ebook-library/uploads/
```
