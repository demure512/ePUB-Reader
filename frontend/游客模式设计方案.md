# 游客模式设计方案

## 📋 功能概述

游客模式允许用户在不登录的情况下使用电子书图书馆的核心功能，所有数据保存在用户本地浏览器中，不会上传到云端。

## 🎯 核心特性

### ✅ 支持的功能
- 上传电子书文件
- 阅读电子书
- 保存阅读进度
- 书籍管理（删除、编辑信息）
- 阅读设置（字体、主题等）
- 书籍分类管理
- 搜索功能

### ❌ 不支持的功能
- 云端数据同步
- 跨设备数据共享
- 用户账户管理
- 数据备份到服务器

## 🏗️ 技术架构

### 数据存储策略
```
游客模式数据存储层次：
├── localStorage (持久化存储)
│   ├── guest_books (书籍元数据)
│   ├── guest_progress (阅读进度)
│   ├── guest_settings (用户设置)
│   └── guest_categories (分类信息)
├── IndexedDB (大文件存储)
│   └── guest_files (电子书文件内容)
└── sessionStorage (临时数据)
    └── current_session (当前会话状态)
```

### 模式切换机制
```
用户访问流程：
登录页面 → 选择模式
├── 登录模式 → 云端数据 + 完整功能
└── 游客模式 → 本地数据 + 核心功能
```

### 2. 数据存储层抽象

#### 2.1 创建存储适配器
```javascript
// src/utils/storageAdapter.js
class StorageAdapter {
  constructor(mode) {
    this.mode = mode // 'cloud' | 'local'
  }
  
  // 书籍数据操作
  async getBooks() {
    if (this.mode === 'cloud') {
      return await cloudBookService.getBooks()
    } else {
      return JSON.parse(localStorage.getItem('guest_books') || '[]')
    }
  }
  
  async saveBook(book) {
    if (this.mode === 'cloud') {
      return await cloudBookService.saveBook(book)
    } else {
      const books = await this.getBooks()
      const newBook = { ...book, id: Date.now(), createdAt: new Date() }
      books.push(newBook)
      localStorage.setItem('guest_books', JSON.stringify(books))
      return newBook
    }
  }
  
  // 阅读进度操作
  async getProgress(bookId) {
    if (this.mode === 'cloud') {
      return await cloudProgressService.getProgress(bookId)
    } else {
      const progress = JSON.parse(localStorage.getItem('guest_progress') || '{}')
      return progress[bookId] || null
    }
  }
  
  async saveProgress(bookId, progressData) {
    if (this.mode === 'cloud') {
      return await cloudProgressService.saveProgress(bookId, progressData)
    } else {
      const progress = JSON.parse(localStorage.getItem('guest_progress') || '{}')
      progress[bookId] = { ...progressData, updatedAt: new Date() }
      localStorage.setItem('guest_progress', JSON.stringify(progress))
    }
  }
}
```

#### 2.2 文件存储管理
```javascript
// src/utils/fileStorage.js
class GuestFileStorage {
  constructor() {
    this.dbName = 'GuestEbookDB'
    this.version = 1
    this.db = null
  }
  
  async init() {
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(this.dbName, this.version)
      
      request.onerror = () => reject(request.error)
      request.onsuccess = () => {
        this.db = request.result
        resolve()
      }
      
      request.onupgradeneeded = (event) => {
        const db = event.target.result
        if (!db.objectStoreNames.contains('files')) {
          db.createObjectStore('files', { keyPath: 'id' })
        }
      }
    })
  }
  
  async saveFile(id, file) {
    const transaction = this.db.transaction(['files'], 'readwrite')
    const store = transaction.objectStore('files')
    
    const fileData = {
      id,
      name: file.name,
      type: file.type,
      size: file.size,
      content: await file.arrayBuffer(),
      uploadedAt: new Date()
    }
    
    return store.add(fileData)
  }
  
  async getFile(id) {
    const transaction = this.db.transaction(['files'], 'readonly')
    const store = transaction.objectStore('files')
    
    return new Promise((resolve, reject) => {
      const request = store.get(id)
      request.onsuccess = () => resolve(request.result)
      request.onerror = () => reject(request.error)
    })
  }
}
```

### 3. Store 层适配

#### 3.1 扩展 book store
```javascript
// src/stores/book.js 扩展
const bookStore = {
  state: {
    books: [],
    currentBook: null,
    storageAdapter: null
  },
  
  actions: {
    // 初始化存储适配器
    initStorage() {
      const authStore = useAuthStore()
      this.storageAdapter = new StorageAdapter(
        authStore.isGuest ? 'local' : 'cloud'
      )
    },
    
    // 获取书籍列表
    async fetchBooks() {
      this.initStorage()
      this.books = await this.storageAdapter.getBooks()
    },
    
    // 上传书籍
    async uploadBook(file, metadata) {
      this.initStorage()
      
      if (this.storageAdapter.mode === 'local') {
        // 游客模式：保存到本地
        const fileStorage = new GuestFileStorage()
        await fileStorage.init()
        
        const bookId = Date.now()
        await fileStorage.saveFile(bookId, file)
        
        const book = await this.storageAdapter.saveBook({
          ...metadata,
          id: bookId,
          fileName: file.name,
          fileSize: file.size,
          fileType: this.getFileType(file.name)
        })
        
        this.books.push(book)
        return book
      } else {
        // 登录模式：上传到云端
        return await this.uploadToCloud(file, metadata)
      }
    }
  }
}
```

const settingsStore = {
  actions: {
    async loadSettings() {
      const authStore = useAuthStore()
      
      if (authStore.isGuest) {
        // 游客模式：从 localStorage 加载
        const settings = localStorage.getItem('guest_settings')
        this.settings = settings ? JSON.parse(settings) : this.getDefaultSettings()
      } else {
        // 登录模式：从云端加载
        await this.loadFromCloud()
      }
    },
    
    async saveSettings() {
      const authStore = useAuthStore()
      
      if (authStore.isGuest) {
        // 游客模式：保存到 localStorage
        localStorage.setItem('guest_settings', JSON.stringify(this.settings))
      } else {
        // 登录模式：保存到云端
        await this.saveToCloud()
      }
    }
  }
}

// src/utils/guestDataExport.js
export class GuestDataExporter {
  async exportData() {
    const data = {
      books: JSON.parse(localStorage.getItem('guest_books') || '[]'),
      progress: JSON.parse(localStorage.getItem('guest_progress') || '{}'),
      settings: JSON.parse(localStorage.getItem('guest_settings') || '{}'),
      categories: JSON.parse(localStorage.getItem('guest_categories') || '[]'),
      exportedAt: new Date().toISOString()
    }
    
    // 导出文件内容
    const fileStorage = new GuestFileStorage()
    await fileStorage.init()
    
    for (const book of data.books) {
      const fileData = await fileStorage.getFile(book.id)
      if (fileData) {
        data.files = data.files || {}
        data.files[book.id] = {
          name: fileData.name,
          type: fileData.type,
          content: Array.from(new Uint8Array(fileData.content))
        }
      }
    }
    
    return data
  }
  
  downloadAsFile(data) {
    const blob = new Blob([JSON.stringify(data, null, 2)], {
      type: 'application/json'
    })
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = `ebook-library-guest-data-${Date.now()}.json`
    a.click()
    URL.revokeObjectURL(url)
  }
}

## 🎯 用户体验流程

```
用户访问 → 登录页面
    ↓
选择游客模式 → 初始化本地存储
    ↓
进入书架页面 → 显示本地书籍
    ↓
上传/阅读书籍 → 数据保存到本地
    ↓
关闭应用 → 数据持久化保存
    ↓
再次访问 → 恢复之前的数据
```

## 💡 技术优势

1. **无缝体验**: 游客模式功能与登录模式基本一致
2. **数据安全**: 本地数据不会泄露到服务器
3. **离线可用**: 完全不依赖网络连接
4. **易于升级**: 可以方便地转换为正式账号
5. **组件复用**: 最大化复用现有代码

这个方案可以让用户在不注册的情况下完整体验应用功能，同时为后续的账号注册和数据迁移提供了平滑的升级路径。
