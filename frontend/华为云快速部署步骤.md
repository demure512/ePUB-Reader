# 华为云快速部署步骤

## 简化部署流程

是的，基本上就是这样！但需要分几个步骤来完成。让我为您详细说明：

## 第一步：准备华为云资源

### 1.1 创建ECS服务器
```bash
# 在华为云控制台创建ECS实例
规格: 2核4GB (s6.large.2)
系统: CentOS 8 或 Ubuntu 20.04
网络: 分配弹性公网IP
安全组: 开放 22, 80, 443, 8080 端口
```

### 1.2 创建RDS数据库
```bash
# 在华为云控制台创建RDS MySQL实例
版本: MySQL 8.0
规格: 2核4GB (db.mysql.s1.medium)
存储: 40GB
网络: 与ECS同一VPC
```

### 1.3 创建OBS存储桶
```bash
# 在华为云控制台创建OBS桶
桶名: your-domain-frontend
权限: 公共读
静态网站托管: 启用
```

## 第二步：上传代码到服务器

### 2.1 连接到ECS服务器
```bash
# 使用SSH连接到您的ECS服务器
ssh root@your_ecs_ip
```

### 2.2 上传项目代码
有几种方式上传代码：

**方式1: 使用Git (推荐)**
```bash
# 在ECS服务器上执行
git clone https://github.com/your-username/ebook-library.git
cd ebook-library
```

**方式2: 使用SCP上传**
```bash
# 在本地电脑上执行
scp -r ./ebook-library root@your_ecs_ip:/opt/
```

**方式3: 使用FTP工具**
- 使用WinSCP (Windows) 或 FileZilla
- 上传整个项目文件夹到服务器

## 第三步：修改配置并运行脚本

### 3.1 修改部署脚本配置
```bash
# 在ECS服务器上编辑配置
cd /opt/ebook-library
vim deploy.sh

# 修改以下变量为您的实际值：
ECS_HOST="your_ecs_ip"           # 您的ECS公网IP
RDS_HOST="your_rds_host"         # RDS数据库内网地址
DB_NAME="ebook_library"          # 数据库名
DB_USER="ebook_user"             # 数据库用户名
DB_PASS="your_secure_password"   # 数据库密码
OBS_BUCKET="your-domain-frontend" # OBS桶名
DOMAIN="your-domain.com"         # 您的域名
```

### 3.2 运行部署脚本
```bash
# 给脚本执行权限
chmod +x deploy.sh

# 运行完整部署
./deploy.sh all
```

## 第四步：配置域名解析

在您的域名服务商处添加DNS解析：
```bash
A记录: your-domain.com -> ECS公网IP
A记录: api.your-domain.com -> ECS公网IP
CNAME记录: www.your-domain.com -> OBS桶域名
```

## 更简单的一键部署脚本

让我为您创建一个更简单的脚本，您只需要修改几个配置就能运行：

### 创建配置文件
```bash
# 在服务器上创建配置文件
cat > config.env << EOF
# 请修改以下配置为您的实际值
ECS_IP=1.2.3.4                    # 您的ECS公网IP
RDS_HOST=rds-xxx.mysql.rds.myhuaweicloud.com  # RDS内网地址
DB_PASSWORD=your_password_123      # 数据库密码
DOMAIN=yourdomain.com             # 您的域名
OBS_BUCKET=yourdomain-frontend    # OBS桶名

# 以下配置一般不需要修改
DB_NAME=ebook_library
DB_USER=ebook_user
EOF
```

### 运行一键部署
```bash
# 加载配置并运行部署
source config.env && ./deploy.sh all
```

## 完整的操作步骤总结

1. **在华为云控制台**：创建ECS、RDS、OBS资源
2. **上传代码**：将项目代码上传到ECS服务器
3. **修改配置**：编辑 `config.env` 文件，填入您的实际配置
4. **运行脚本**：执行 `./deploy.sh all` 完成部署
5. **配置域名**：在域名服务商处添加DNS解析记录

## 预计时间

- 创建华为云资源：10-15分钟
- 上传代码：2-5分钟
- 修改配置：2-3分钟
- 运行部署脚本：5-10分钟
- 配置域名：2-3分钟

**总计：约20-35分钟完成整个部署**

## 注意事项

1. **确保ECS和RDS在同一VPC网络**
2. **记录好RDS的内网地址和密码**
3. **确保安全组规则正确配置**
4. **域名需要已备案（如果使用国内服务器）**

## 如果遇到问题

1. **查看脚本日志**：脚本会显示详细的执行过程
2. **检查服务状态**：`systemctl status ebook-library`
3. **查看应用日志**：`tail -f /opt/ebook-library/logs/application.log`
4. **参考完整文档**：查看 `华为云部署指南.md` 获取详细故障排查步骤
