# 🔌 桌面端离线模式指南

## 📋 功能概述

桌面端游客模式现在支持完全离线使用，即使在断网情况下也能正常使用所有功能。

## ✨ 离线功能特性

### 🎯 完全离线支持
- ✅ **书籍管理**: 上传、阅读、删除书籍
- ✅ **阅读进度**: 自动保存和恢复阅读位置
- ✅ **用户设置**: 主题、字体、阅读偏好等
- ✅ **封面显示**: EPUB封面提取和显示
- ✅ **数据持久化**: 所有数据本地存储，重启后保持

### 🔄 智能同步机制
- ✅ **网络状态检测**: 实时监控网络连接状态
- ✅ **离线队列**: 离线时的操作会排队等待网络恢复
- ✅ **自动同步**: 网络恢复后自动同步待处理操作
- ✅ **状态指示**: 实时显示在线/离线状态和同步进度

## 🚀 使用方式

### 1. 启动离线模式
```bash
# 启动应用
npm run dev

# 或构建桌面应用
npm run electron:build
```

### 2. 进入游客模式
1. 打开应用
2. 点击"游客模式"按钮
3. 现在可以完全离线使用

### 3. 离线功能测试
1. **断开网络连接**
2. **上传书籍** - 正常工作
3. **阅读书籍** - 正常工作
4. **保存进度** - 自动保存到本地
5. **修改设置** - 立即生效并保存

## 🔧 技术实现

### 存储架构
```
桌面端离线存储
├── 浏览器环境
│   ├── localStorage (设置、状态)
│   └── IndexedDB (书籍、进度、封面)
└── Electron环境
    └── 文件系统 (完整本地存储)
```

### 网络检测机制
- **实时监控**: 每5秒检查网络状态
- **多重检测**: 浏览器API + DNS检测
- **智能回退**: 网络请求失败时自动使用本地数据

### 离线队列系统
```javascript
// 离线操作会自动加入队列
offlineQueue = [
  { type: 'saveProgress', data: {...}, timestamp: 1234567890 },
  { type: 'uploadBook', data: {...}, timestamp: 1234567891 },
  { type: 'saveSettings', data: {...}, timestamp: 1234567892 }
]
```

## 🔍 故障排除

### 常见问题

**Q: 离线模式下上传的书籍看不到封面？**
A: 检查EPUB文件是否包含封面，系统会自动提取并转换为base64格式存储。

**Q: 网络恢复后同步失败？**
A: 查看浏览器控制台，可能是认证过期，重新登录即可。

**Q: 离线数据丢失？**
A: 检查浏览器存储设置，确保允许本地数据存储。
