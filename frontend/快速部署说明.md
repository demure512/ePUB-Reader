# 🚀 快速部署说明

## 您的服务器配置
- **CPU**: 4 vCPUs (鲲鹏)
- **内存**: 8 GB  
- **系统**: Ubuntu 24.04 Server
- **架构**: ARM64

## 📋 部署步骤

### 1. 上传项目代码到服务器
```bash
# 方式1: 使用scp上传整个项目
scp -r ./ebook-library-dev-ffg root@your_server_ip:/opt/

# 方式2: 在服务器上直接下载
ssh root@your_server_ip
cd /opt
# 如果有Git仓库的话
git clone https://your-repo-url.git ebook-library-dev-ffg
```

### 2. 连接到服务器并运行部署脚本
```bash
# SSH连接到服务器
ssh root@your_server_ip

# 进入项目目录
cd /opt/ebook-library-dev-ffg

# 给脚本执行权限
chmod +x deploy-single.sh

# 运行部署脚本
./deploy-single.sh
```

### 3. 等待部署完成
脚本会自动完成以下操作：
- ✅ 安装Java 17 (ARM64版本)
- ✅ 安装Node.js 18 (ARM64版本)
- ✅ 安装MySQL数据库
- ✅ 安装Nginx反向代理
- ✅ 构建Spring Boot后端
- ✅ 构建Vue.js前端
- ✅ 配置系统服务
- ✅ 启动所有服务

### 4. 访问应用
部署完成后，脚本会显示您的服务器IP地址，直接在浏览器访问即可！

## 🎯 就是这么简单！

**总结：只需要3个命令**
```bash
scp -r ./ebook-library-dev-ffg root@your_server_ip:/opt/
ssh root@your_server_ip
cd /opt/ebook-library-dev-ffg && chmod +x deploy-single.sh && ./deploy-single.sh
```
