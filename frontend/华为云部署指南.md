# 电子书库应用华为云部署指南

## 概述

本指南将帮助您将电子书库应用部署到华为云，包括前端Vue.js应用和后端Spring Boot应用的完整部署流程。

## 架构概览

```
华为云部署架构
├── 前端 (Vue.js)
│   ├── 华为云OBS (对象存储) - 静态网站托管
│   └── 华为云CDN - 内容分发加速
├── 后端 (Spring Boot)
│   ├── 华为云ECS (弹性云服务器)
│   └── 华为云RDS (关系型数据库)
└── 域名与SSL
    ├── 华为云DNS - 域名解析
    └── 华为云SSL证书管理
```

## 部署步骤

### 第一步：准备华为云环境

#### 1.1 创建华为云账号
- 访问 [华为云官网](https://www.huaweicloud.com/)
- 注册账号并完成实名认证
- 充值账户余额（建议至少100元用于测试）

#### 1.2 创建项目和区域选择
- 登录华为云控制台
- 选择合适的区域（推荐：华北-北京四 或 华东-上海一）
- 创建新项目或使用默认项目

### 第二步：数据库部署 (RDS)

#### 2.1 创建RDS MySQL实例
```bash
# 配置参数
实例规格: db.mysql.s1.medium (2核4GB) 或更高
数据库版本: MySQL 8.0
存储类型: 高IO
存储空间: 40GB (可扩展)
网络: VPC网络
安全组: 允许3306端口访问
```

#### 2.2 配置数据库
```sql
-- 创建数据库
CREATE DATABASE ebook_library CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户
CREATE USER 'ebook_user'@'%' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON ebook_library.* TO 'ebook_user'@'%';
FLUSH PRIVILEGES;
```

#### 2.3 导入数据库结构
```bash
# 使用提供的SQL文件初始化数据库
mysql -h your_rds_host -u ebook_user -p ebook_library < backend/src/main/resources/init-sync-tables.sql
```

### 第三步：后端部署 (ECS)

#### 3.1 创建ECS实例
```bash
# 实例配置
规格: s6.large.2 (2核4GB) 或更高
镜像: CentOS 8.2 或 Ubuntu 20.04
系统盘: 40GB SSD
网络: VPC网络 (与RDS同一VPC)
安全组: 开放22(SSH), 8080(应用), 80(HTTP), 443(HTTPS)端口
弹性IP: 绑定弹性公网IP
```

#### 3.2 环境准备
```bash
# 连接到ECS实例
ssh root@your_ecs_ip

# 安装Java 17
yum update -y
yum install -y java-17-openjdk java-17-openjdk-devel

# 验证Java安装
java -version

# 安装Maven (用于构建)
wget https://archive.apache.org/dist/maven/maven-3/3.8.6/binaries/apache-maven-3.8.6-bin.tar.gz
tar -xzf apache-maven-3.8.6-bin.tar.gz
mv apache-maven-3.8.6 /opt/maven
echo 'export PATH=/opt/maven/bin:$PATH' >> /etc/profile
source /etc/profile

# 创建应用目录
mkdir -p /opt/ebook-library
cd /opt/ebook-library
```

#### 3.3 部署后端应用
```bash
# 上传代码到服务器 (使用scp或git)
# 方法1: 使用git
git clone https://your-repository-url.git
cd ebook-library-backend

# 方法2: 使用scp上传本地代码
# scp -r ./backend root@your_ecs_ip:/opt/ebook-library/

# 修改配置文件
vim src/main/resources/application.properties
```

#### 3.4 配置application.properties
```properties
# 数据库配置
spring.datasource.url=jdbc:mysql://your_rds_host:3306/ebook_library?useSSL=true&serverTimezone=Asia/Shanghai
spring.datasource.username=ebook_user
spring.datasource.password=your_secure_password
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JPA配置
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=false
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect

# 文件上传配置
spring.servlet.multipart.max-file-size=100MB
spring.servlet.multipart.max-request-size=100MB
app.upload.dir=/opt/ebook-library/uploads

# 服务器配置
server.port=8080
server.servlet.context-path=/

# 跨域配置
app.cors.allowed-origins=https://your-domain.com,https://www.your-domain.com

# 日志配置
logging.level.com.ebook=INFO
logging.file.name=/opt/ebook-library/logs/application.log
```

#### 3.5 构建和启动应用
```bash
# 构建应用
mvn clean package -DskipTests

# 创建启动脚本
cat > /opt/ebook-library/start.sh << 'EOF'
#!/bin/bash
cd /opt/ebook-library/backend
nohup java -jar -Xmx2g -Xms1g target/ebook-library-*.jar > /opt/ebook-library/logs/app.log 2>&1 &
echo $! > /opt/ebook-library/app.pid
echo "应用已启动，PID: $(cat /opt/ebook-library/app.pid)"
EOF

# 创建停止脚本
cat > /opt/ebook-library/stop.sh << 'EOF'
#!/bin/bash
if [ -f /opt/ebook-library/app.pid ]; then
    PID=$(cat /opt/ebook-library/app.pid)
    kill $PID
    rm /opt/ebook-library/app.pid
    echo "应用已停止"
else
    echo "应用未运行"
fi
EOF

# 设置执行权限
chmod +x /opt/ebook-library/start.sh
chmod +x /opt/ebook-library/stop.sh

# 创建日志目录
mkdir -p /opt/ebook-library/logs
mkdir -p /opt/ebook-library/uploads

# 启动应用
./start.sh
```

#### 3.6 配置系统服务
```bash
# 创建systemd服务文件
cat > /etc/systemd/system/ebook-library.service << 'EOF'
[Unit]
Description=Ebook Library Application
After=network.target

[Service]
Type=forking
User=root
WorkingDirectory=/opt/ebook-library/backend
ExecStart=/opt/ebook-library/start.sh
ExecStop=/opt/ebook-library/stop.sh
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 启用服务
systemctl daemon-reload
systemctl enable ebook-library
systemctl start ebook-library

# 检查服务状态
systemctl status ebook-library
```

### 第四步：前端部署 (OBS + CDN)

#### 4.1 构建前端应用
```bash
# 在本地开发环境中
cd frontend

# 修改生产环境配置
vim .env.production
```

#### 4.2 配置.env.production
```env
# API基础URL (后端ECS的公网IP或域名)
VITE_API_BASE_URL=https://api.your-domain.com

# 应用标题
VITE_APP_TITLE=电子书库

# 其他配置
NODE_ENV=production
```

#### 4.3 构建生产版本
```bash
# 安装依赖
npm install

# 构建生产版本
npm run build

# 构建完成后，dist目录包含所有静态文件
```

#### 4.4 创建OBS桶
```bash
# 在华为云控制台创建OBS桶
桶名称: your-domain-frontend (全局唯一)
区域: 与ECS相同区域
存储类别: 标准存储
访问权限: 公共读
静态网站托管: 启用
索引文档: index.html
错误文档: index.html (用于SPA路由)
```

#### 4.5 上传前端文件
```bash
# 方法1: 使用华为云控制台上传
# 将dist目录下的所有文件上传到OBS桶根目录

# 方法2: 使用OBS CLI工具
# 安装obsutil
wget https://obs-community.obs.cn-north-1.myhuaweicloud.com/obsutil/current/obsutil_linux_amd64.tar.gz
tar -xzf obsutil_linux_amd64.tar.gz
chmod +x obsutil_linux_amd64_*/obsutil

# 配置obsutil
./obsutil config -i your_access_key -k your_secret_key -e obs.cn-north-4.myhuaweicloud.com

# 上传文件
./obsutil cp dist/ obs://your-domain-frontend/ -r -f
```

#### 4.6 配置CDN加速
```bash
# 在华为云控制台创建CDN加速域名
加速域名: www.your-domain.com
源站类型: 对象存储
源站地址: your-domain-frontend.obs.cn-north-4.myhuaweicloud.com
回源协议: HTTP
缓存配置: 
  - HTML文件: 不缓存
  - CSS/JS文件: 缓存30天
  - 图片文件: 缓存7天
```

### 第五步：域名和SSL配置

#### 5.1 域名解析配置
```bash
# 在华为云DNS服务中添加解析记录
主域名: your-domain.com
  - A记录: @ -> ECS公网IP (后端API)
  - A记录: api -> ECS公网IP (后端API)
  - CNAME记录: www -> CDN域名 (前端)
```

#### 5.2 SSL证书配置
```bash
# 申请免费SSL证书
证书类型: DV单域名证书
域名: your-domain.com, www.your-domain.com, api.your-domain.com

# 下载证书并配置到相应服务
# 1. CDN配置SSL证书 (前端HTTPS)
# 2. ECS配置SSL证书 (后端HTTPS) - 可选，使用Nginx反向代理
```

#### 5.3 配置Nginx反向代理 (可选)
```bash
# 在ECS上安装Nginx
yum install -y nginx

# 配置Nginx
cat > /etc/nginx/conf.d/ebook-library.conf << 'EOF'
server {
    listen 80;
    server_name api.your-domain.com your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.your-domain.com your-domain.com;

    ssl_certificate /path/to/your/certificate.crt;
    ssl_certificate_key /path/to/your/private.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    client_max_body_size 100M;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

# 启动Nginx
systemctl enable nginx
systemctl start nginx
```

### 第六步：监控和维护

#### 6.1 配置日志监控
```bash
# 安装日志监控工具
yum install -y logrotate

# 配置日志轮转
cat > /etc/logrotate.d/ebook-library << 'EOF'
/opt/ebook-library/logs/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 644 root root
    postrotate
        systemctl reload ebook-library
    endscript
}
EOF
```

#### 6.2 配置自动备份
```bash
# 创建数据库备份脚本
cat > /opt/ebook-library/backup.sh << 'EOF'
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/opt/ebook-library/backups"
mkdir -p $BACKUP_DIR

# 备份数据库
mysqldump -h your_rds_host -u ebook_user -p'your_secure_password' ebook_library > $BACKUP_DIR/db_backup_$DATE.sql

# 备份上传文件
tar -czf $BACKUP_DIR/uploads_backup_$DATE.tar.gz /opt/ebook-library/uploads/

# 删除30天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +30 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +30 -delete

echo "备份完成: $DATE"
EOF

chmod +x /opt/ebook-library/backup.sh

# 添加到定时任务
echo "0 2 * * * /opt/ebook-library/backup.sh" | crontab -
```

## 故障排查

### 常见问题
1. **后端无法连接数据库**
   - 检查RDS安全组配置
   - 验证数据库连接字符串
   - 确认用户权限

2. **前端无法访问后端API**
   - 检查CORS配置
   - 验证API域名解析
   - 确认防火墙规则

3. **文件上传失败**
   - 检查磁盘空间
   - 验证文件权限
   - 确认上传目录存在
